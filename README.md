# House-price-prediction-project
House price prediction project using machine learning

## Project Overview
This project is based on House Price Prediction using Machine Learning. It analyzes housing data of Gurgaon city and helps users understand housing prices through data analysis and predictive models.

The project uses Python, Machine Learning and Streamlit to provide an interactive dashboard for housing price analysis.

## Objectives
- To analyze the housing dataset.
- To perform data cleaning and preprocessing.
- To understand patterns and trends in house prices.
- To build machine learning prediction models.
- To compare model performance.

## Technologies Used
- Python 3.13
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Machine Learning Algorithms
1. Linear Regression
2. Random Forest Regressor

## Dataset
The project uses the `gurgaon_city.csv` dataset containing housing-related information for Gurgaon city.

## Project Files
- `app.py` – Main Streamlit application.
- `EDA.ipynb` – Exploratory Data Analysis.
- `gurgaon_city.csv` – Dataset.
- `requirements.txt` – Required Python libraries.

## Model Evaluation
The models are evaluated using:
- R² Score
- RMSE (Root Mean Squared Error)

## How to Run the Project

**Step 1:** Install the required libraries:

```bash
py -3.13 -m pip install -r requirements.txt
```

**Step 2:** Run the Streamlit application:

```bash
py -3.13 -m streamlit run app.py
```

**Step 3:** Open the local URL displayed in the terminal.

## Conclusion
This project demonstrates how Machine Learning can be used for house price prediction. It combines data analysis, visualization and predictive modelling to provide an interactive housing price analysis system.
